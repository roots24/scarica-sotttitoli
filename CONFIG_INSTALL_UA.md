# Посібник зі встановлення та конфігурації - YouTube Subtitle Downloader Pro

## 🛠 Технічний аналіз архітектури
**YouTube Subtitle Downloader Pro** розроблено за трьома рівнями для забезпечення модульності, зручності обслуговування та простоти розповсюдження.

### 1. Рівень інтерфейсу користувача (GUI Layer) - `gui.py`
Інтерфейс розроблено за допомогою **customtkinter**, бібліотеки, яка розширює Tkinter для забезпечення сучасного вигляду, що відповідає актуальним операційним системам.
- **Асинхронність**: Усі важкі операції (завантаження, пошук мов, оновлення FFmpeg) виконуються в окремих потоках, щоб уникнути блокування GUI (*main loop*).
- **Взаємодія**: Керує введенням даних користувачем, відображенням системних логів та візуальним зворотним зв'язком через смужку прогресу.

### 2. Рівень основної логіки (Core Logic Layer) - `logic.py`
Цей рівень виступає оркестратором між інтерфейсом і зовнішніми залежностями.
- **Інтеграція yt-dlp**: Використовує потужну бібліотеку `yt-dlp` для вилучення метаданих відео та завантаження субтитрів (як ручних, так і автоматично згенерованих).
- **Керування потоками**: Впроваджує систему власних винятків (`SubtitleError`, `NetworkError` тощо) для передачі специфічних помилок до GUI.
- **Пост-обробка**: Координує конвертацію форматів (WebVTT $\rightarrow$ SRT), взаємодіючи з рівнем FFmpeg.

### 3. Рівень керування FFmpeg (FFmpeg Management Layer) - `ffmpeg_manager.py`
Спеціалізований модуль для абстракції бінарного розширення, необхідного для конвертації файлів.
- **Автоматизація**: Перевіряє наявність FFmpeg у системі; у разі відсутності автоматично завантажує останню стабільну збірку з GitHub (BtbN).
- **Конфігурація**: Керує збереженням шляху до виконуваного файлу через файл `config.json`.
- **Версіонування**: Порівнює локальну версію зі віддаленою, щоб повідомити користувача про наявність оновлень.

## 🚀 Посібник зі встановлення (Розробка)

### Системні вимоги
- **Python**: Версія 3.8 або вище.
- **Операційна система**: Windows 10/11 (рекомендовано).

### Кроки для встановлення
1. Клонуйте або завантажте папку з проєктом.
2. Відкрийте термінал у головній директорії.
3. Встановіть необхідні залежності через pip:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустіть програму:
   ```bash
   python gui.py
   ```

## 📦 Інструкції зі створення пакету (.exe)

Для розповсюдження програми як одного виконуваного файлу для Windows рекомендується використовувати **PyInstaller**.

### Команда для компіляції
Виконайте наступну команду в терміналі (PowerShell):
```powershell
$ctk_path = python -c "import customtkinter; import os; print(os.path.dirname(customtkinter.__file__))"; pyinstaller --noconsole --onefile --add-data "$($ctk_path);customtkinter/" gui.py
```

### Технічні деталі прапорців (flags):
- `--noconsole`: Запобігає відкриттю вікна терміналу (CMD) при запуску програми, відображаючи лише GUI.
- `--onefile`: Пакує все в один файл `.exe` для полегшення розповсюдження.
- `--add-data`: **Критично важливо**. `customtkinter` потребує своїх файлів тем та активів (JSON, зображення) для коректного відображення інтерфейсу. Команда вище автоматично визначає шлях до бібліотеки у вашому середовищі Python.

### Керування бінарними файлами FFmpeg
Створений виконуваний файл не містить FFmpeg всередині, щоб уникнути надмірних розмірів. Програма автоматично:
1. Шукає існуюче встановлення.
2. Автоматично завантажує його в папку `/ffmpeg` відносно виконуваного файлу при першому запуску або через кнопку "Оновити FFmpeg".

Якщо ви бажаєте включити FFmpeg у пакет, вам потрібно додати папку `ffmpeg/` за допомогою опції `--add-data` PyInstaller та змінити `ffmpeg_manager.py`, щоб він читав файли з тимчасової директорії PyInstaller (`sys._MEIPASS`).
