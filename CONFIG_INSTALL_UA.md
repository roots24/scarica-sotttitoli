# Посібник зі встановлення та конфігурації - YouTube Subtitle Downloader Pro

## 🛠 Технічний аналіз архітектури
**YouTube Subtitle Downloader Pro** розроблений за трирівневою архітектурою для забезпечення модульності, зручності обслуговування та простоти розповсюдження.

### 1. Рівень користувацького інтерфейсу (GUI Layer) - `gui.py`
Інтерфейс розроблено з використанням **customtkinter**, бібліотеки, яка розширює Tkinter для забезпечення сучасного вигляду, що відповідає актуальним операційним системам.
- **Асинхронність**: Всі важкі операції (завантаження, пошук мов, оновлення FFmpeg) виконуються в окремих потоках (threads), щоб уникнути блокування графічного інтерфейсу (*main loop*).
- **Взаємодія**: Керує введенням даних користувачем, відображенням системних логів та візуальним зворотним зв'язком за допомогою смуги прогресу.

### 2. Рівень основної логіки (Core Logic Layer) - `logic.py`
Цей рівень виступає в якості оркестратора між інтерфейсом та зовнішніми залежностями.
- **Інтеграція yt-dlp**: Використовує потужну бібліотеку `yt-dlp` для вилучення метаданих відео та завантаження субтитрів (як ручних, так і автоматично згенерованих).
- **Керування потоками**: Реалізує систему користувацьких виключень (`SubtitleError`, `NetworkError` тощо) для передачі конкретних помилок до GUI.
- **Пост-обробка**: Координує конвертацію форматів (WebVTT $\rightarrow$ SRT), взаємодіючи з рівнем FFmpeg.

### 3. Рівень керування FFmpeg (FFmpeg Management Layer) - `ffmpeg_manager.py`
Спеціалізований модуль для абстракції бінарних файлів, необхідних для конвертації файлів.
- **Автоматизація**: Перевіряє наявність FFmpeg у системі; у разі відсутності автоматично завантажує останню стабільну збірку з GitHub (BtbN).
- **Конфігурація**: Керує збереженням шляху до виконуваного файлу через файл `config.json`.
- **Версіонування**: Порівнює локальну версію з віддаленою, щоб повідомити користувача про доступність оновлень.

## 🚀 Посібник зі встановлення (для розробки)

### Системні вимоги
- **Python**: Версія 3.8 або вище.
- **Операційна система**: Windows 10/11 (рекомендовано).

### Кроки для встановлення
1. Клонуйте або завантажте папку з проєктом.
2. Відкрийте термінал у головній директорії.
3. Встановіть необхідні залежності через pip:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустіть додаток:
   ```bash
   python gui.py
   ```

## 📦 Інструкції зі створення виконуваного файлу (.exe)

Для розповсюдження програми як одного виконуваного файлу для Windows рекомендується використовувати **PyInstaller**.

### Команда для компіляції
Виконайте наступну команду в терміналі:
```bash
pyinstaller --noconsole --onefile --add-data "C:/Path/To/Python/Lib/site-packages/customtkinter;customtkinter/" gui.py
```

### Технічні деталі прапорців (flags):
- `--noconsole`: Запобігає відкриттю вікна терміналу (CMD) при запуску програми, відображаючи лише GUI.
- `--onefile`: Пакує все в один файл `.exe` для зручності розповсюдження.
- `--add-data`: **Критично важливо**. `customtkinter` потребує своїх файлів тем та активів (JSON, зображення) для коректного відображення інтерфейсу. Ви повинні вказати реальний шлях до папки `customtkinter` у вашому середовищі Python.

### Керування бінарними файлами FFmpeg
Створений виконуваний файл не включає FFmpeg всередині, щоб уникнути надмірного розміру. Програма автоматично керуватиме:
1. Пошуком існуючого встановлення.
2. Автоматичним завантаженням у папку `/ffmpeg` відносно виконуваного файлу при першому запуску або через кнопку "Оновити FFmpeg".

Якщо ви бажаєте включити FFmpeg у пакет, вам потрібно буде додати папку `ffmpeg/` за допомогою опції `--add-data` у PyInstaller та змінити `ffmpeg_manager.py`, щоб він зчитував файли з тимчасової директорії PyInstaller (`sys._MEIPASS`).
